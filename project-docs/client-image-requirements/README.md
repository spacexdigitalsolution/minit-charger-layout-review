### General Asset Guidelines for Client Delivery:
1. **Hardware Cutouts:** All product listings require high-resolution 4K transparent PNGs with alpha channels and zero color fringing.
2. **On-Location Photography:** Industrial field shots must feature real-world commercial operations (airports, distribution centers, bus depots) with clean safety adherence (PPE, hi-vis).
3. **Aspect Ratios & Responsive Images:** Standard heroes use 16:9 widescreen (`2560x1440`), editorial banners use 21:9 (`2560x1200`), cards use 4:3 (`1200x900`), and square cutouts use 1:1 (`2000x2000`).
4. **Format Deliverables:** High-resolution uncompressed master PNGs/TIFs or 24-bit JPGs (Q90+), which will be automatically optimized to Next.js WebP/AVIF via the asset pipeline.
