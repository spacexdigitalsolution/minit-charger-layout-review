How to Setup Document Tabs in Google Docs

1

Enable Document Tabs in your Google Doc

Open a blank Google Doc, click the Document tabs icon in the left margin (or select Tools > Document tabs).

2

Create a Tab for each Website Page

Click + Add tab on the left sidebar. Name each tab after the website page (e.g., 01. Homepage, 04. Altus II, etc.).

3

Copy and Paste with Full Formatting Preserved

Select any tab here, click 📋 Copy Current Tab, then switch to Google Docs and press Ctrl+V (or Cmd+V). All tables, colored priority tags, and shot instructions transfer seamlessly.

4

Or Import the Entire Master Document at Once

You can also click 📑 Copy All for Google Docs or open MASTER-GOOGLE-DOC.html directly in Google Docs via File > Open > Upload.
