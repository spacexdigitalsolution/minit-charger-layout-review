### Asset 03.1: Products Hero Lineup Banner

- **Target File Path / Component Reference:** `/assets/homepage/All Products Lineup.webp`
- **Recommended Dimensions & Aspect Ratio:** `2560 x 1000 px (Panoramic Banner)`
- **Asset Type:** 3D CAD Studio Composite
- **File Format:** WebP / JPG
- **Production Priority:** P0 (Launch Critical)

#### Creative Shot Description & Framing Directive:
> Panoramic studio composite shot displaying all 8 flagship hardware chargers (Altus II, Magnus, Mobilus, Momentus, Maximus, Durus, CellTrac, and Cumulus monitor) standing side-by-side in height order against a sleek graphite studio backdrop with subtle floor reflections.

#### Photographer / 3D Artist Instructions:

* Use neutral, high-key studio lighting with realistic metallic specular reflections and subtle ambient occlusion.
* Verify all hardware dimensions match official Minit Charger engineering schematics.
